# Proyecto de Organización de Tareas - POO

Este repositorio contiene las tareas y ejercicios realizados durante el curso de **Programación Orientada a Objetos**. El proyecto ha sido adaptado para gestionar de manera eficiente los códigos de cada unidad.

## Estudiante
* **Nombre:** Santiago Vaca
* **Institución:** Universidad Estatal Amazónica

## Estructura del Proyecto
El proyecto utiliza un script principal llamado `Dashboard.py` que permite:
1. Navegar entre las carpetas de las Unidades (1 y 2).
2. Visualizar el código fuente de los ejercicios sin abrirlos externamente.
3. Ejecutar los scripts en una ventana de terminal independiente.

## Instrucciones de Uso
1. Ejecute el archivo principal: `python Dashboard.py`.
2. Utilice el menú numérico para navegar por las unidades y tareas.
3. Al seleccionar un script, el sistema mostrará el código y preguntará si desea ejecutarlo.

## Tecnologías Utilizadas
* Python 3.x
* Librerías: `os`, `subprocess`
